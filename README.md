# The Window

A film that was never made, remembered badly, forty times.

A model is shown one frame and one sentence. It describes what it thinks is happening, then describes the next shot. A renderer paints that shot. The model never sees the script, the transcript, or the film as a whole. Only the last image and the premise. Then it does it again.

The point is not to make a film. The point is to watch a model remember one.

We usually describe model memory as storage. This project treats it as reconstruction. Each frame is built on a slightly wrong account of the one before it, and the errors accumulate. A woman at a window becomes a shape at a window, then a shape, then a poster. The poster is not a style applied at the end. It is what the model produces when asked to summarise a film it only half remembers.

That drift is the work.

The look is fixed on purpose. One visual language, one renderer, one palette family. If the style moved too, we could not tell whether the change came from the model or from us.

Why a film? Because film is continuity. A story only works if the system can hold who is where, what changed, and what comes next. Continuity is the clearest test of memory we have, and the model will fail it in a way that is legible. Not random noise. A slow collapse toward the most typical image of the thing. The poster is the attractor.

Why local and open? Because the claim is about a particular model's prior, not about "AI" in general. An 8B open model runs on a laptop, the weights are fixed, the seed is fixed, the renderer is fixed. Anyone can rerun it and get the same forgetting.

The output is forty frames, the model's written continuity notes, one drift chart, and the poster it makes at the end. The notes are the evidence. The frames are what it looks like when a model tells a story to itself and slowly loses the thread.

It is not a call sheet, not a website, and not quite a film. It is a portrait of a model's idea of a film, made by letting it forget.
